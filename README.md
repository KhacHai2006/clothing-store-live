# OOP Analysis & Design — Clothing Store (PHP)

Website bán quần áo bằng PHP thuần, kết nối MySQL, đồ án môn **Phân tích thiết kế hướng đối tượng** — kèm sơ đồ phân tích thiết kế (`bao_cao/`).

## Cài đặt & chạy

1. Tạo database `clothingshop`, import `db/clothingshop.sql`.
2. Đặt thư mục project vào `htdocs` của XAMPP.
3. Mở `http://localhost/PTTK_HDT-website_ban_quan_ao`.
